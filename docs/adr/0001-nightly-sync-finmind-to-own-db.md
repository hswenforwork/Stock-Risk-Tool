# 收盤後批次同步 FinMind 資料到自有資料庫，回測只讀自有資料庫

系統對外公開，但 FinMind 免費方案每小時只有 600 次請求（Backer 1,600 次），而且必須逐檔查詢，每週日 00:00–03:00 還會停機維護。如果每次回測都即時呼叫 FinMind，很快就會用完額度。因此後端在每個交易日 FinMind 更新後（17:30 之後）批次同步資料到自有資料庫，回測一律只讀自有資料庫，不在使用者請求的路徑上呼叫 FinMind。

## 考慮過的選項

- **使用者回測時才抓取並快取**：冷門標的第一次回測會很慢，而且額度消耗取決於使用者行為、無法預測，所以不採用。
