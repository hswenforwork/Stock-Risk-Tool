# 網站維持免費、非商業用途，以符合 FinMind 授權

FinMind 的 Free、Backer、Sponsor 方案只允許非商業用途，商業用途（收費、廣告、SaaS）必須購買 Sponsor Pro（月繳 NT$3,330）。所有方案都禁止再散布原始資料、禁止建立實質等同於 FinMind 的鏡像 API，並要求標示資料來源「FinMind」。因此網站先以免費、非商業的形式公開，使用 Backer 方案；決定收費前必須先升級到 Sponsor Pro。系統不得提供下載原始股價資料的功能，頁面必須標示資料來源。
