# 持倉採「層」模型，策略是依序比對、每天只執行一條的規則清單

策略是一張**有順序的規則清單**，每條規則是「條件組合 → 動作」，動作包括進場、加碼、減碼、出場、停損、停利。每個交易日收盤後由上往下比對，只執行第一條成立的規則，在下一個交易日開盤成交。停損不強制排在第一，但如果沒排在最前面，編輯器會顯示警告。

持倉採**層**模型：預計投入資金依批次比例分成多層（預設 50/30/20）。加碼填入下一個空層；減碼與出場賣掉最上面那一層（後進先出）；停損一次出清所有層。所以持倉永遠不超過預計投入資金的 100%，同一段持倉中，加碼和減碼可以交替發生。

## 考慮過的選項

- **固定的動作優先順序（停損 > 停利 > 出場 > 加碼 > 進場）**：使用者希望自己控制優先順序，所以不採用。
- **持倉只能先加碼、後減碼**：這樣無法模擬實際交易中反覆加減碼的操作，所以不採用。
